### Ilker Aslan, PhD

Economist and lecturer at Kalaidos University of Applied Sciences, Zürich. I work on insurance, reinsurance and catastrophe risk, and on post-Keynesian monetary economics. Before returning to research and teaching I was a treaty reinsurance underwriter at Swiss Re and AXIS Re.

[Website](https://ilkeraslan.github.io) · [Google Scholar](https://scholar.google.com/citations?user=typ8zTgAAAAJ) · [SSRN](https://papers.ssrn.com/sol3/cf_dev/AbsByAuth.cfm?per_id=4975975) · [ORCID](https://orcid.org/0000-0001-9241-9420)

Each repository below holds the code and data behind one paper and reproduces its tables and figures. The README of each repository lists the data sources and how to run the code.
